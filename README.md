### 👨‍💻 Кто я

Привет! Я **Алан** — разработчик из Осетии. Пишу на **C# / .NET** (ASP.NET Core, WPF, EF Core) и **Flutter**, автоматизирую рутину на **Python**.

Главная тема, которой я горжусь, — **проекты на осетинском языке**: чат-боты, переводчик, игра и обучающие приложения. Первый в истории осетинский GPT-бот, первый осетинский переводчик на Flutter, Wordle на осетинском — всё это здесь.

- 🔭 Сейчас: развиваю экосистему проектов на осетинском языке
- 🌱 Учу новые технологии и стараюсь доводить идеи до продукта
- 🤝 Открыт к коллаборации над интересными проектами

### 🚀 Избранные проекты

- [AlanaGPT](https://github.com/AlanTsarakov/AlanaGPT) — Первый чат-бот, говорящий на осетинском языке.
- [alana_max_bot](https://github.com/AlanTsarakov/alana_max_bot) — Первый чат-бот для MAX на осетинском языке.
- [ossetian_translator](https://github.com/AlanTsarakov/ossetian_translator) — Осетинский переводчик — клиент на Flutter + [API на ASP.NET Core](https://github.com/AlanTsarakov/OssetianTranslatorAPI).
- [GuessWord](https://github.com/AlanTsarakov/GuessWord) — Игра по правилам Wordle с осетинскими словами.
- [flutter_ossetian_learning_app](https://github.com/AlanTsarakov/flutter_ossetian_learning_app) — Мобильное приложение для изучения осетинского языка.
- [Avzag](https://github.com/AlanTsarakov/Avzag) + [WebApiAvzag](https://github.com/AlanTsarakov/WebApiAvzag) — Клиент и Web API приложения для изучения осетинского языка.
- [WeatherApp](https://github.com/AlanTsarakov/WeatherApp) — Приложение на WPF с прогнозом погоды по городам.
- [MailingBot](https://github.com/AlanTsarakov/MailingBot) — Telegram-бот, автоматически добавляющий email-адреса в Unisender.
